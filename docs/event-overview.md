# Event Overview

## TL/IRL: AI for Security & Security for AI

**Date:** October 20, 2026  
**Location:** Georgian, Toronto  
**Hosts:** Georgian × AI Sec Eng Toronto  
**Format:** In-person practitioner talks, Q&A, and networking

## Core Themes

The event focused on two directions of AI security: **AI for Security** and **Security for AI**. A third theme emerged strongly around **Agent supply-chain security** — treating skills, MCP-connected tools, scripts, hooks, and dependencies as executable trust boundaries rather than passive configuration.
